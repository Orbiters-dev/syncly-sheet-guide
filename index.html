Pipeline

Per-Influencer Processing Flow

Each influencer is processed one at a time. The full cycle must complete before moving to the next person.

PHASE 1 Pre-Outreach Validation

1. WebFetch from Syncly Sheet

Fetch the influencer's row as CSV using their Profile URL as the match key. If multiple rows exist, select the one with the richest Transcript.

Google Sheets CSV WebFetch
Skip: If WebFetch returns empty, skip immediately. No email can be written without Syncly data.

2. Three Pre-Filters

If any filter triggers, the influencer is immediately skipped and auto-blacklisted via update_sheet.py --blacklist.

Geo Filter
Non-US/CA locations in Bio (country names, cities, flag emojis)
Account Type
Brand, meme, or curation accounts (2+ signals required)
Email Validation
Malformed addresses, temp domains, suspicious domains

4. Fit Score Calculation (0–100)

fit_scorer.py takes Syncly data as JSON and scores how well the influencer fits the Onzenna brand.

Parenting Keyword Density
Max 40pts — keyword count in Summary + Theme + Transcript + Caption
Transcript Richness
Max 20pts — 200+ chars = 20pts, 50+ = 15pts
Bio Relevance
Max 20pts — 3+ parenting keywords in Bio = 20pts
Theme + Competitor
Max 20pts — parenting theme (10) + competitor brand experience (10)
40+ points → Proceed to email writing
0–39 points → Skip + auto-blacklist

Key Things to Know

Critical details for anyone taking over this workflow.

Sheet ID Changes Per Batch

The content extraction sheet gets a new ID with each batch. Always verify config.json values for spreadsheet_id and data_tab before starting.

Drafts Only — Never Auto-Send

The agent only creates Gmail Drafts. A human must review and send manually. This is by design.

One-at-a-Time Processing

Batch-fetching N influencers at once causes personalization quality to plummet. Always complete one full cycle before moving to the next person.

Transcript Is King

Column T (Transcript) is the most important source for personalization. When multiple rows exist, always pick the row with the richest Transcript.

Know Your Gmail Accounts

onzenna.com = Gmail MCP (draft creation + dedup).
zezebaebae.com = Local Python (dedup only). Don't mix them up.

Agent Role Separation

Custom = initial outreach only. Reply handling and follow-ups are managed by the Manager agent. Both send as Jane.
